# Legal IP Skill Extractor

把公开法律行业内容拆成可复用的内容技能，并用官方法律来源做事实复核入口。

## 什么时候使用

- 已经有公开作品链接、账号、标题或可见文案，想提炼出稳定的开头、文案、悬念、讲述、镜头和互动模式。
- 想把一条内容升级成可调用的 `SKILL.md`、选题卡、口播骨架或拍摄单。
- 想把民法典、公司法、企业破产法、劳动合同法、个人信息保护法、数据安全法等法源接入内容生产，但不把法条直接当成个案结论。

## 输入与输出

输入：公开、可回溯的作品链接与账号关系；官方法律来源；明确的目标平台和内容场景。

输出：

1. `records`：每条样本的来源、标题、可见文案摘要和七维技能标签。
2. `patterns`：按账号和技能维度聚合的高频模式。
3. `law_refs`：与选题相关的官方法律入口、有效性状态和适用主题。
4. `skill_prompt`：可以继续生成口播稿、镜头清单、复盘卡的调用模板。

## 标准流程

1. **来源门禁**：保留原始链接和来源状态；独立作品页、账号列表标题、搜索候选分开标注。
2. **结构提取**：从公开可见信息中拆 `opening / copy / suspense / narration / camera / interaction / compliance`。
3. **聚合蒸馏**：统计同一账号的高频模式，形成“这个账号稳定怎么讲”的方法卡。
4. **法源映射**：只把官方数据库中的法律作为复核入口，记录法律名称、施行日期和相关主题。
5. **内容生成**：先写场景和问题，再引用法源范围，最后写“需结合事实、证据和最新有效文本复核”。
6. **发布前复核**：不承诺胜诉、不虚构案件细节、不泄露隐私，不用片面标题替代完整法律判断。

## 本地运行

```bash
node tools/legal_ip_skill_extractor.mjs
```

它读取 `douyin-feishu/data/latest.json` 与 `douyin-feishu/data/legal_corpus.json`，生成 `douyin-feishu/data/skill_registry.json`，供 GitHub Pages 的面板读取。

## 使用边界

这个 Skill 是内容研究与结构化工具，不提供个案法律意见，不替代律师、法条原文、司法解释或最新有效性核验。
