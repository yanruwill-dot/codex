WHO IT IS FOR

适合谁，不适合谁

小班不是把大班缩小，而是把每个人的行业、任务和商业问题放到桌面上，一起做、当场看、及时改。

适合

  • 零基础，但希望尽快把 AI 用进日常工作的人
  • 想实操 OpenClaw、Codex，而不是只听概念的人
  • 想把行业经验整理成知识库、智能体或工作流的人
  • 正在寻找“行业＋AI”产品、服务或商业化方向的人

不适合

  • 只想听趋势、不愿意动手的人
  • 期待上一堂课就保证收入、流量或成交的人
  • 需要算法研究、模型训练等深度技术课程的人
  • 不愿意核对数据边界、隐私和工具使用规则的人

LEARNING PATH

不是背工具，从问题走到商业化验证

OpenClaw、Codex 与其他工具会随版本变化，稳定不变的是从真实问题、行业任务、可用结果走到商业价值的路径。

  1. 01

    先把问题说清楚

    明确目标、输入、判断标准和不能出错的边界，不让 AI 在模糊要求里乱猜。

  2. 02

    用 OpenClaw 或 Codex 做出结果

    根据任务选择合适工具，从内容、研究、文件、代码或业务方案中选一件，当场完成可检查的产出。

  3. 03

    把结果接进行业场景

    把个人经验、行业知识和岗位流程放进提示结构、知识库、智能体或工作流，让方案对本行业真正有用。

  4. 04

    做商业化落地判断

    说清服务谁、解决什么问题、交付什么、如何验收，以及哪些结果不能承诺，再决定产品化、服务化或企业内部落地。

FROM TOOL TO BUSINESS

四层实操落地，不停在“会用工具”

每一层都要有可见产出；是否继续向下一层走，以任务是否稳定、结果是否可验收为准。

01

OpenClaw 实操

理解任务、上下文、记忆、Skills 与自动化协作，完成一个能运行的个人或业务流程。

02

Codex 实操

让 Codex 读取资料、处理文件、制作页面或工具，并用测试和预览核对真实结果。

03

行业＋AI落地

从本人行业的客户问题、知识、内容或岗位流程出发，做出一个贴合场景的最小可行方案。

04

商业化落地

把方案整理成明确的目标客户、价值、交付物、验收标准和风险边界，验证它能否成为产品或服务。

WINDOWS PATH

不是把 Mac 操作照搬到 Windows

课堂按当期版本选择真实可用路径：Codex 可用 Windows 桌面端原生 PowerShell 或 WSL2；OpenClaw 可用 Windows Hub、PowerShell CLI 或 WSL2。现场会核对系统版本、权限、安装条件和安全边界。

FAQ

大家最常问的

是不是只教 OpenClaw？

不是。课程包含 OpenClaw 与 Codex 等工具实操，更重要的是把工具接进真实行业任务，完成行业＋AI和商业化落地练习。具体工具清单与版本以当期书面课程通知为准。

Windows 电脑可以参加吗？

可以。课程提供 Windows 实操路径。Codex 可在 Windows 桌面端原生使用 PowerShell，也可配置 WSL2；OpenClaw 可按当期官方支持选择 Windows Hub、PowerShell CLI 或 WSL2。具体安装方式、系统要求和工具版本以当期课程通知与官方文档为准。

颜汝有阿里达摩院认证吗？

颜汝本人说明持有阿里达摩院相关认证。本页面暂未取得可公开核验的证书原件，因此不公开证书全称、编号或有效状态，也不把认证信息作为课程效果证明。

零基础能参加吗？

能。基础小班课面向零基础学习者、老板和企业管理者，重点是把 AI 用进真实工作。进阶智能体、编程和复杂自动化需要另行核对基础与课程版本。

小班到底多少人？

采用小班制，以保证现场实操和辅导密度。具体人数会随场地、课程版本和助教配置变化，以当期官方书面通知为准。

在哪里上课？价格是多少？

课程在长沙线下开展。日期、场地、费用和名额属于当期信息，报名付款前请核对智焰科技或颜汝团队发布的当期书面课程通知。

上完能保证赚钱吗？

不能。课程帮助你学习方法、完成实操并建立可复用的工作方式，但不能把参加课程等同于收入、流量、成交或经营结果。

和企业内训有什么区别？

小班课主要帮助个人掌握工具实操、行业任务拆解和商业化落地基础；企业内训会围绕具体岗位、团队流程、知识边界和组织落地机制另行设计。

这个智焰科技是哪家公司？

本页面中的智焰科技特指颜汝团队在长沙开展的 AI 课程与企业服务，不指北京、广州、浙江或其他同名主体。
