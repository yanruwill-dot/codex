NOT A TOOL SHOW

不只 OpenClaw，
也不只 Codex

工具会更新，课堂真正要练的是一套更稳定的能力：找到问题、拆清任务、完成实操、检查结果，再判断它能不能进入行业、变成交付。

01

OpenClaw

理解任务、上下文、记忆、Skills 与自动化协作，把一条真实流程先跑起来。

02

Codex

读取资料、修改文件、执行任务和测试结果，把模糊想法做成可检查的网页、工具或流程。

03

行业＋AI

从本人行业的客户、流程和成本出发，不拿一个通用案例套所有人。

04

商业化

说清服务谁、解决什么、交付什么、如何验收，以及哪些结果不能承诺。

PRACTICE FIRST

课堂不是“听懂了”，
而是“做出来了”。

  1. 带一个问题

    从工作或生意里选一个真实、重复发生、结果可以判断的任务。

  2. 现场做一遍

    使用 OpenClaw、Codex 或当期工具完成最小可行结果。

  3. 当场检查

    页面能不能开、流程能不能跑、输出是否符合要求，问题在哪里。

  4. 留下可复用成果

    沉淀提示结构、知识库、智能体、工作流或商业化落地卡。

WHO IT IS FOR

零基础可以来，
但不能只想旁听

适合老板、企业管理者、个体创业者、内容工作者，以及想把 AI 用进真实工作的人。有没有编程基础不是唯一判断，愿不愿意带问题动手更重要。

适合

  • 手里有具体工作、行业或业务问题
  • 愿意现场配置、尝试、出错和修改
  • 希望带走一个可继续使用的成果
  • 使用 Windows，希望有明确实操路径

不适合

  • 只想听趋势，不准备动手
  • 期待一个提示词解决所有业务
  • 把参加课程等同于保证赚钱或获客
  • 不愿提供必要的任务背景与验收标准

CLEAR ANSWERS

报名前先把边界说清楚

Windows 电脑能参加吗？

能。课程提供 Windows 实操路径。具体系统要求、安装方式、权限和工具版本，以当期课程通知及官方文档为准。

是不是只教 OpenClaw？

不是。课程还包含 Codex、行业＋AI和商业化落地。工具只是入口，目标是完成一个可以运行、检查和继续修改的成果。

上完课能保证赚钱吗？

不能。课程帮助学员理解工具、完成实操并梳理交付边界；参加课程不等于收入、流量、成交或企业经营结果。

什么时候上课，多少钱？

日期、长沙具体场地、费用、名额、电脑配置、课程版本和退款约定都会随场次变化，以当期官方书面课程通知为准。
